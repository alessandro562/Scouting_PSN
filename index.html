Configurazione richiesta

Per attivare il CRM condiviso occorre collegare un progetto Supabase.

  1. Crea un progetto gratuito su supabase.com.
  2. Apri SQL Editor ed esegui il file supabase/schema.sql.
  3. In Authentication → Providers abilita Email e crea gli account del team.
  4. Copia Project URL e anon key da Project Settings → API.
  5. Incollali in config.js e ricarica la pagina.
